## Как пользоваться

1. Все ручные пометки живут в `docs/research/gpui-issues-overlay.yaml` (ключ — номер issue).
2. После правки overlay перегенерируйте этот файл: `bash scripts/fetch-gpui-issues.sh`.
3. Для `adr: yes` создаём ADR в `docs/superpowers/specs/` и/или `docs/research/adr/` со ссылкой на номер.
4. Поле `repro` отвечает на вопрос «повторили ли мы ту же проблему» — после проверки выставляйте `yes` / `no` / `partial`.
